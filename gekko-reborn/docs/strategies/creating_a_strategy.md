# 如何编写策略

## 约定

策略应当：

- 输入：历史 K 线（DataFrame）或结构化行情
- 输出：带信号列的结果（例如 `signal`），或直接输出交易决策对象
- 可配置：通过 config 控制参数与行为

## 建议实现步骤

1. 在 `backend/app/strategy/` 新建策略文件
2. 继承项目的 `BaseStrategy`（以代码中的基类定义为准）
3. 实现 `analyze` 之类的核心方法
4. 在 backtest router 或 scheduler 中接入该策略

## 注意事项

- 回测与运行时应尽量共享策略代码，避免两套逻辑漂移
- 任何涉及资金与风控的逻辑应集中在交易执行层，而非散落在策略里
