# 回测

## 目标

在历史 K 线数据上运行策略，输出：

- 权益曲线（equity curve）
- 交易明细（trades）
- 关键指标（收益、最大回撤、胜率等）

## 交互入口

- 前端：策略管理页（配置 + 运行回测 + 展示结果）
- 后端 API：`POST /backtest/run`

## 运行流程（当前实现）

1. 拉取历史 K 线（market service）
2. 实例化策略（示例策略：GoldenCross、AIStrategy）
3. 回测引擎执行，生成 trades 与 metrics
4. 返回给前端渲染

## 重要边界

- 目前回测策略多为示例级别，参数/手续费/滑点模型仍可增强
- 数据质量（缺口、时间对齐）会直接影响回测可靠性
