# 实盘交易（规划中）

## 目标

在模拟交易之上打通实盘链路，包含：

- 交易所鉴权与密钥管理
- 下单/撤单/查询订单状态
- 资产与仓位同步
- 基础风控（额度、频率、最大回撤、黑白名单等）

## 当前代码状态

- 后端已具备 API Key 管理接口，但对密钥加密/权限隔离尚需完善
- 下单执行的实盘分支当前未实现（会抛出 NotImplementedError）

## 建议落地路径

1. 完成交易所适配层（ccxt 或自研 wrapper）
2. 补齐订单状态机与撮合回执处理
3. 增加风控与审计日志
4. 引入任务队列/后台 worker，把行情同步与策略执行解耦
