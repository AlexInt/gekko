# 范围与边界

## 当前已覆盖（MVP）

- 数据：支持通过 API 导入历史 K 线数据并落库（TimescaleDB/PostgreSQL）
- 回测：支持选择策略、参数、时间范围运行回测并展示结果
- 模拟交易：订单创建与模拟撮合（后端 `is_paper=true`）
- AI：支持发起 LSTM 训练、保存模型工件、登记模型元数据，并在 AI 策略中加载
- 前端：提供仪表盘、数据管理、策略回测、AI 模型等页面的基础 UI

## 暂未覆盖（明确不做 / 规划中）

- 实盘交易：订单路由到真实交易所的撮合与风控（当前后端会抛出 `NotImplementedError`）
- 分布式任务队列：仓库依赖中包含 Celery/Redis，但当前训练/导入多数仍为同步执行或 APScheduler 触发
- 账户/权限体系：目前未实现完整的用户认证授权

## 安全边界（必须遵守）

- 交易所密钥不得以明文日志输出；后端应对 `secret` 做加密/脱敏存储（当前为简化实现，后续必须补齐）
- 默认仅建议在本地/内网暴露后端端口；公网部署应加反向代理与鉴权
