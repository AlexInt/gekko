# 需求文档 - Phase 6: Web 前端开发

## 介绍

本阶段旨在为 KoiQuant 提供一个现代化的 Web 前端界面，使用户能够直观地监控市场、管理策略、执行回测以及控制实盘交易。前端将基于 Next.js 构建，通过 REST API 与后端交互。

## 需求

### 需求 1 - 仪表盘 (Dashboard)

- **用户故事**:
  - 作为用户，我希望登录后能立即看到账户总资产、持仓分布和最近的活动订单，以便快速了解系统状态。

#### 验收标准
1. **When** 用户进入首页，**The** 系统 **Shall** 显示当前账户的总权益（法币 + 代币折算）。
2. **The** 系统 **Shall** 展示当前持有的资产列表（币种、数量、当前价值）。
3. **The** 系统 **Shall** 显示最近的 N 条活跃订单或最近交易记录。

### 需求 2 - 市场行情 (Market View)

- **用户故事**:
  - 作为用户，我希望查看特定交易对的 K 线图，以便分析市场走势。

#### 验收标准
1. **When** 用户选择交易对（如 BTC/USDT）和时间周期（如 1h），**The** 系统 **Shall** 加载并渲染 K 线图（使用 Lightweight Charts）。
2. **The** 系统 **Shall** 支持在图表上叠加技术指标（如 MA, RSI，如果后端支持或前端计算）。

### 需求 3 - 策略回测 (Strategy Backtest)

- **用户故事**:
  - 作为用户，我希望能够选择策略、设置参数和时间范围进行回测，并查看回测结果报告。

#### 验收标准
1. **When** 用户进入回测页面，**The** 系统 **Shall** 列出所有可用策略。
2. **When** 用户配置回测参数（开始时间、结束时间、初始资金、交易对）并点击“开始回测”，**The** 系统 **Shall** 发送请求并在完成后展示回测结果。
3. **The** 系统 **Shall** 以图表形式展示资金曲线，并显示关键指标（总收益、最大回撤、夏普比率等）。

### 需求 4 - AI 模型管理 (AI Model Management)

- **用户故事**:
  - 作为用户，我希望能触发 AI 模型训练，并查看模型的预测结果。

#### 验收标准
1. **The** 系统 **Shall** 展示当前 AI 模型的列表及其状态（如：训练中、就绪）。
2. **When** 用户点击“训练模型”，**The** 系统 **Shall** 允许配置训练参数并启动训练任务。
3. **The** 系统 **Shall** 展示模型对未来走势的预测信心或信号。

### 需求 5 - 实盘交易控制 (Live Trading Control)

- **用户故事**:
  - 作为用户，我希望能启动或停止自动交易机器人，并实时监控其运行状态。

#### 验收标准
1. **The** 系统 **Shall** 提供明显的“启动/停止”按钮来控制实盘交易进程。
2. **When** 交易机器人运行时，**The** 系统 **Shall** 实时（或定时轮询）更新日志或状态指示器。
